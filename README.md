# 🤖 AI Sales Agent & CRM Automation

An AI-powered sales automation system built with **n8n** that automates lead qualification, personalized sales outreach, CRM updates, and sales team notifications.

## 🚀 Overview

This project connects an AI Agent with Google Sheets, Gmail, and Telegram to create an automated sales workflow.

The system takes lead information from a CRM, analyzes the lead using AI, determines lead quality and status, generates a personalized sales email, sends the email through Gmail, updates the CRM, and notifies the sales team through Telegram.
